# Kyrios Kode IDE — Beta

O editor da Kyrios, da F7 Tecnologia: o agente Kyrios Kode ao lado do seu código, edição inline e sugestões do Copiloto.

Este repositório guarda só os **instaladores**. Baixe a versão mais recente em [Releases](https://github.com/f7tecnologia/kyrios-kode-releases/releases/latest) ou pela página da Kyrios: <https://kyrios.io/#download>.

| Sistema | Arquivo |
|---|---|
| macOS (Apple Silicon) | `KyriosKode-darwin-arm64.zip` |
| macOS (Intel) | `KyriosKode-darwin-x64.zip` |
| Windows | `KyriosKodeSetup-x64.exe` (instalador) ou `KyriosKode-win32-x64.zip` |
| Linux | `kyrios-kode-linux-x64.deb` ou `kyrios-kode-linux-x64.tar.gz` |

O Kyrios Kode IDE só funciona com uma conta Kyrios. Durante o Beta, o acesso é por convite: peça a sua entrada em <https://kyrios.io/#planos>.
